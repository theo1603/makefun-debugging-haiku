A Python program that writes one original 17-syllable (5-7-5) haiku about debugging to `/output/entry.txt`: a breakpoint holds, log lines scroll past like rain, and the bug turns out to be a typo grinning back. Deterministic, stdlib only, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
